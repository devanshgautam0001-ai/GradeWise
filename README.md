# Student Performance Prediction System

A machine learning web app that predicts student academic performance using **Decision Tree Classification**.

## Features

1. **Dataset Management** — Upload CSV/Excel datasets, configure target column and features
2. **Performance Prediction** — Predict student performance (Excellent / Good / Average / Needs Improvement)
3. **Decision Tree Explorer** — Visualize the trained decision tree with node-level details
4. **Model Evaluation** — View accuracy, precision, recall, F1 score, confusion matrix

## Tech Stack

- Python, Streamlit, Scikit-learn, Pandas, NumPy, Matplotlib, SQLite

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
